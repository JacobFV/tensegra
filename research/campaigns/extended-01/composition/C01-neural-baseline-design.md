# C01 fair neural-only comparator design v1

Prospective design only, before P01/R05 confirmation gates. No composed path is implemented or authorized to run. This document makes baseline choices reviewable; a frozen C01 experiment registration, actual checkpoint identifiers and CPU validation must follow successful entry audits before any implementation. Every learned hidden/workspace width is1024; nonce features remain32.

## Equal evidence and what each arm computes

All primary arms receive the same complete public four-record instruction inventory, eleven-handle candidate inventory, explicitly typed numeric table, requested destination and threshold/polarity query. They receive no selected record index, selected operand values, operation target, computed return value, binding labels or answer in forward. Train-only labels may supervise the same primitive/pointer/value/answer components. Display names are unused presentation metadata; renaming them is an input no-op, never lexical generalization.

The hybrid is the frozen P01 actor, predicted-arity schema adapter and existing exact primitive, followed by frozen R04/R05 at supplied delay. The neural comparator must be allowed the numeric witnesses, including multiplication's value-bearing witness. It may exploit any public correlation. Query-only is a diagnostic prior baseline, never the claimed neural comparator. Report original-mixture results separately from balanced values, since integer rounding, multiplication witnesses and Boolean comparison produce strong public regularities.

Primary neural comparator N1 starts with exactly the same learned ProposalModel architecture and may initialize from the same frozen P01 checkpoint. Its soft operand-pointer distributions retrieve public numeric/type features differentiably; this is learned weighted selection, not exact argmax gather. Each table entry supplies value/16, integer/float/absent indicators and an availability indicator. Concatenate the two retrieved feature vectors, the five operation probabilities, and the public threshold/8 and polarity. Feed a1024→1024 GELU MLP with a direct two-class answer head and an auxiliary33-value head. The input projection has the exact resulting feature count (2×5+5+2=17). Softmax is only a feature transformation. Numeric values for absent/destination rows are zero with explicit absence indicators. The nonexistent unary second operand need not be learned as a pointer: predicted negation probability is available in the operation channels, and the head can learn its irrelevance. No symbolic add/sub/mul/neg/compare or exact query calculation is allowed in neural-only forward.

N1 may fine-tune its lowerer end-to-end; the hybrid keeps P01 frozen. This is an intentional advantage to a strong baseline, disclosed in trainable parameter counts. Auxiliary primitive and required-pointer losses retain the same allowed P01 supervision, auxiliary value loss the same finite scalar supervision used by R04, and answer loss matches R05. The answer head reads its learned hidden state directly: it is not forced through a33-class scalar bottleneck. Report a frozen-lowerer N1 variant as a matched-interface diagnostic, not the sole comparator.

To ensure that soft selection/feature averaging does not artificially limit N1, predeclare N2 as a stronger all-evidence contextual comparator. Encode each instruction token from its destination32, two ordered argument32 vectors and operation5 one-hot; each table token from key32, value/16, three type indicators and public operand/null/destination role indicators; and one query token from destination32, threshold/8 and polarity. Separate learned linear projections map each token kind to1024, plus learned token-kind embeddings. Two ordinary self-attention/GELU transformer blocks (eight heads, feed-forward1024, no order positions for shuffled records/table; ordered operand slots remain separate within each instruction token) operate on these16tokens. A query-token MLP emits the direct answer and auxiliary scalar predictions. The same operation/pointer auxiliary heads may attach to its query state; implementation details must be frozen with the later protocol and parameter audit. All attention is dense learned attention over the full observable evidence. No hard routing, oracle selection or privileged graph is supplied. An exact-address neural arithmetic diagnostic can localize N1/N2 failures but is privileged and cannot replace either primary comparator.

## Prospective fitting and selection

One development initialization proposes fitting16384 fresh public examples, calibration2048, validation4096; both N1 and N2 get the identical examples, labels and sample-index stream. Proposed exposure is4000updates×256=1024000presentations, evaluated at0/250/500/1000/2000/4000. Proposed AdamW learning rates are a small prespecified pair(.001,.0003), weight_decay.01; select each arm only by calibration answer count, then earlier checkpoint, then the first registered learning rate. Treat this as a search with its full cost reported. A profile must check feasibility, and recipe changes before any development outcomes require a versioned registration. No baseline is intentionally stopped while its calibration curve is still rising: if the last1000updates improve calibration by at least0.5percentage points, a predeclared equal-exposure8000update extension for both N1 and N2 is eligible, subject to coordinator budget and confirmation recipe freeze. Preserve first-endpoint outcomes.

These are proposed allocations rather than a GPU request. Fresh data namespaces must be allocated by the coordinator after checking P01/R05 populations, then committed before generation. Confirmation uses three independent initializations and fresh fitting/calibration/validation populations; it cannot reuse the development validation population. Freeze baseline recipes before C01 confirmation outcomes. Report from-scratch N1 separately if feasible; do not conflate a P01-initialized comparator with a model trained from scratch. The hybrid's historical backbone/readout/consumer pretraining differs from baseline acquisition; report all inherited training and measured current fitting costs rather than claiming matched total compute. Fairness is equal observable evidence and strong training opportunity, with compute/parameter discrepancies explicit.

N1/N2 have no persistent return channel: their clean predictions are reused across externally supplied delays and unrelated return-memory distractors because all original instruction/table/query evidence is complete. Repeating those predictions is paired evaluation, not additional independent samples. The hybrid's delayed-access difficulty is a separate architectural constraint. No neural-only baseline should be forced to forget its evidence to manufacture a hybrid advantage. Under wrong/drop/swap return interventions, these comparators still see their original instruction/table/query and therefore legitimately preserve original-answer predictions. Interventions establish causal hybrid return use; they are not ordinary accuracy comparisons against an unmanipulated neural model. For swapped input-record interventions, every arm instead receives the same changed public records and gets actually supplied labels.

## Required reporting and decision boundary

Keep N1/N2 clean answer accuracy, primary hybrid original-answer accuracy, oracle-lowering hybrid, oracle-return hybrid, exact-copy engineering interface and exact arithmetic/query ceiling separate. Report paired disagreements, original and actually supplied answers, changed-answer supports, wrong destinations/primitives, schema/range refusals and float-zero/type/value/operator strata. Lowering errors remain errors even when binary answers coincide. An absent/refused return has no supplied-answer label. Neural-only arithmetic-error reports use the auxiliary value head as a diagnostic; the direct answer head remains its primary output.

A strong neural-only tie or win is a valid outcome. This design tests whether a scheduled exact primitive plus persistent learned return access improves a bounded task under stated costs; it cannot establish unique attention advantage, learned planning, language comprehension, numerical-range generalization or a calibrated joint confidence. C01 promotion still requires audited >=98% fresh three-population P01 and R05 interfaces before implementation, and its own subsequently registered end-to-end criterion afterward.
