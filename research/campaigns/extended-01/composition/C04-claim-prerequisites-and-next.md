# Composition claim prerequisites and stopping decision

**C04 supports a scoped consumed-interface claim, not a general workspace advantage.** Three frozen lineages pass the registered one-operation pipeline and causal checks; N1 roles also passes both answer gates much faster, and supplied exact-copy slightly exceeds workspace delay16 accuracy. The default decision is to stop this composition branch with those alternatives visible. No additional orchestration is justified merely by available budget.

## Optional next discriminating question, only if scientifically needed

If the next objective is specifically **whether learned return binding can select the relevant fact when several valid returns compete**, the most discriminating extension is a separately registered two-return task: two valid runtime returns with independent destination identities are presented, then a later public query selects one destination. Counterbalance return order and query destination; swap an irrelevant return while holding the selected fact fixed, then swap only the selected return. This isolates binding and interference instead of adding a longer predetermined execution chain.

That would require a new learned selection/interface acquisition before any composition claim. Retain an exact destination-keyed store/gather engineering baseline and a strong neural attention/recurrent comparator given the same complete public event history, plus the existing sole-return task as a regression control. Do not hide witness information from the neural comparator to manufacture a benefit. Freeze matched histories, exposure, chosen-fact labels, changed-fact support, all-attempted denominators and end-to-end resource accounting before fresh outcomes; disclose any larger architecture or new input representation. Success would establish only multi-return binding, not autonomous orchestration or superiority to an explicit keyed store.

This is a recommendation note only: no implementation, data generation, acquisition, profile or GPU allocation is proposed for the current campaign. If multi-return binding is not an explicit research objective, the discriminating action is to retain C04's negative necessity/efficiency conclusion and stop.
