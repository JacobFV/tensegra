# S10: frozen public-schema decoding (exploratory CPU diagnostic)

Hypothesis: learned scores spend errors on compiler bookkeeping that can be supplied without inferring the actual term associations. No training, checkpoint inference, score assignment, threshold tuning, or confirmation data access.

Frozen population: S01/S03/S04 final TRAIN128 and DEV512 archived raw/calibrated predictions. Compare unchanged baseline, schema mask, deterministic bookkeeping plus unchanged S05 reference rule, and both. Primary exact canonical graphs; micro typed/ordered F1; paired repair/regression; introduced/removed gold edge errors; predicted node and scope counts. This is a programmed public compiler-contract intervention, not acquired semantics.

Rules justified directly by semantic_graph.compile_term: contains scope→term; declares scope→entity; refers_to ident→entity; argument pred/rel/node→term; item tuple/list→term; field:* record/app→term; binds term→term; binding_scope pred→scope. Term means any compiler kind except scope/entity. No fixed count, position, depth, tree shape, root, or gold attribute is used. Narrower lesson-specific constraints are excluded. The tested compiler supports one construction scope, not general lexical scopes.

Bookkeeping replaces contains/declares only when exactly one active predicted scope exists, connecting it to all active predicted term/entity nodes respectively. Otherwise this part abstains and preserves baseline relations. S05 reference equality is unchanged: all active ident/entity pairs with matching nonnegative copied public-token identity are emitted, including all duplicate matches; missing matches produce no references. Record both cases. Bookkeeping-only pairs have slot -1; when a conflicting learned structural relation shares the pair, preserve its slot and record the conflict (single pair-slot representation limitation). Learned argument/item/field/binds/binding_scope associations and structural slots are preserved except schema-invalid edges removed by mask arms. No guaranteed full graph semantics.

Gold is supplied only to dataset audit and metric scoring, never decoder forward. Compiler-wide constraints will be checked on hand-constructed terms covering every compiler branch and the full 8,704 TRAIN/DEV cached graphs before any result analysis. A failed schema audit stops dependent evaluation. Outputs retain compact exact changed edge/slot lists and original archive hashes for reconstruction.

No selection: report every arm/checkpoint/policy and all per-example outcomes. Existing inspected DEV is diagnostic, not fresh confirmation. CPU wall limit 300 seconds including evaluation/export; no GPU allocation, width remains frozen 1024. Stop on budget or invalid assumptions rather than change rules after outcomes. Source/config/protocol committed before run. Independent reviewer replays raw metrics and verifies target separation.
