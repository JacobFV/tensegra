## Small public-text alternative if workspace acquisition remains weak

A compact **text encoder plus autoregressive graph decoder with a learned copy pointer** is a stronger discriminating alternative than another residual read into fixed canonical node queries. Encode only the full public token sequence with positional/hash features; predict a variable-length sequence describing node kinds/values/copies and labeled ordered edges, including a learned stop decision. The decoder creates node identifiers as it emits them, instead of allocating all graph nodes from128canonical learned queries through eight workspace rows. Gold serialized graphs are teacher-forced targets during training only. At inference there are no supplied graph nodes, alignments, spans, edges, arities, role masks, exact equality operations or parser output. Invalid/incomplete serialization counts as graph failure; do not repair it with gold information.

This is not a repeat of S06's token-state replacement feeding the existing canonical query decoder, nor S07's occurrence-target change. It changes the output-allocation and training interface, so it is a deliberately different public-text learner, **not** an isolated proof that one workspace component caused failure. Retain ordinary tokenization, ontology and supervised graph targets as disclosed priors. Original node ordering can define training serialization, but node count and output length remain predicted. The same first-identity copy contract can be retained; the model must still learn references and edges. No gold token-to-node alignment is needed to instantiate candidate nodes.

The smallest meaningful development comparison would keep the S15 mixed4096 constructions, total construction presentations, existing TRAIN/DEV distinction and whole-graph metric, with one fixed serialization and a small fixed decoder (e.g. two layers, chosen before outcomes). Test whether the alternative can fit actual TRAIN graphs **and** acquire fresh known-motif DEV, retaining heldout3×4as a separate result. Compare with archived S18 endpoints; do not spend another full baseline training run if its recipe is unchanged. Teacher forcing, additional parameters, decoder-token exposure and loss geometry differ and must be reported; do not claim matched FLOPs, optimization or architecture-only attribution. No implementation/count/profile is selected here. Audit serialization invertibility, variable-node/copy support, public-only inference and all-shape capacity before proposing any run.
