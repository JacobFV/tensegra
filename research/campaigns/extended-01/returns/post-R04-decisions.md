# Prospective decisions after R04

No branch launches before the complete R04 raw/provenance audit. Keep all primary and balanced outcomes; the balanced grid is diagnostic and cannot replace the registered mixture. All later experiments require source/config freeze and coordinator scheduling.

## Aggregate scalar contract passes, but float or rare-value tails remain weak

A narrow returned-fact-use study may consume the actual registered mixture: unchanged generator prevalence, 33 bounded half-unit classes, covered delays 0/1/2/4/8/16 and two/eight distractors. Do not silently substitute integer-only or easy values. Keep delay 32 as a separately labeled extrapolation test. Train a downstream neural decision from the frozen learned scalar accessor and public query, preserving the proposed wrong-value, dropped-return and swapped-return interventions. Report changed-answer support and agreement with both original and supplied facts. Query-only and privileged exact-value ceilings diagnose whether the return is used.

Evaluate the same learned consumer separately on a typed full-value grid. If stratified use is poor, state that the registered-mixture result does not extend to uniform subtype/value reliability. The scalar contract is not a six-field retention pass and does not establish broad reintegration or recurrent reasoning.

## Aggregate scalar contract fails

Use the balanced grid and paired ordinary-population errors to identify the next question. Poor zero-step reconstruction points toward a phase/readout issue; errors concentrated at long delays with intact short delays point toward late-state accessibility; consistent neighboring-value confusions across phases motivate an explicitly numerical readout test; a few undersampled type/value/operator combinations motivate controlled balanced exposure. These are hypotheses, not automatic diagnoses.

Choose one smallest intervention only after the evidence distinguishes it. Keep the 1,024-wide backbone, memory and exact scalar task fixed unless a new protocol explicitly tests one of those. A per-phase consumer or value-conditioned loss must not be bundled with a new encoder. Preserve the failed R04 confirmation; do not tune on it and claim a repeat confirmation. New development and subsequent fresh confirmation remain separate.

## Independent engineering reference: learned addressing with exact copying

This is a different interface, not a reconstruction repair. Supply several immutable typed return records with independent random identities and a noisy query identifying one record. A learned matcher chooses which identity to address; the runtime then copies the stored exact value. Vary order, distractors and identities so selecting the correct row is necessary. No gold row index or gold scalar may enter the actor.

Report address accuracy, copied value accuracy conditional on correct address, and end-task accuracy separately. Duplicate values must not inflate address accuracy. Wrong-value intervention changes the addressed record's value while preserving identity; drop removes that record with an explicit missing-address target; swap exchanges values across identities while preserving query identity. Score agreement with both original and actually supplied contents. Exact copying is a programmed guarantee; addressing is learned. This reference cannot satisfy the workspace-only reconstruction gate or authorize general autonomous composition.
