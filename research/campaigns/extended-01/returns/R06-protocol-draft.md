This is an independent exploration prompted by R04's balanced-grid float-zero ingestion failure. It does not alter frozen R04/R05 interfaces, thresholds or current composition eligibility. No new phase-conditioned consumer, encoding, recurrent backbone, loss or memory is introduced.

Use historical wide backbone 12 first, explicitly selected because of the observed tail failure. Compare two fresh scalar-head fits from the same original wide head, each with 16,384 distinct events, delays 0/1/2/4/8/16, two distractors, 900 CE updates, batch256, AdamW .003, and the same sampled-row RNG stream. Both have 33,825 parameters and 230,400 optimizer presentations. The sole selected intervention is the fitting population.

Generate one fixed fresh 65,536-event CPU pool with the unchanged retention generator. The original-mixture arm takes its first 16,384 events. The balanced arm selects 315 or316 events per legal type/value pair (52 strata), totaling exactly16,384; a preregistered permutation chooses the four strata receiving the extra event. Record selected indices, exact overlap between the arms, support by type/value/operator, and all event hashes. Abort if the fixed pool cannot supply any required stratum. Duplicate rows do not count as new events.

This balances legal type/value pairs, not primitive combinations or unconditional scalar-label mass. It intentionally changes type prevalence relative to the original mixture. Train-only normalization remains the unchanged fitting rule, so its statistics can differ as a consequence of population selection; record them and avoid a claim that normalization is held numerically fixed.
