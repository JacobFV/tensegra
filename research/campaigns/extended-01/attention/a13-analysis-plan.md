# A13 paired analysis and provenance plan

Prepared before main release/outcomes, without changing policies, sources, populations or caps. `research/tools/campaign_a13_analysis.py` consumes archived arrays only and hashes every raw result input into its output. It performs no model inference, selection or training. Run it on `a13-main` after the immutable receipt/raw commit, followed by independent raw audit. Validate the analysis implementation on the already completed32-event profile only; that validation does not select a policy or predict main counts.

For each shape and policy, retain the four actual event counts of task correct/wrong crossed with full queried mean-route correct/wrong. Compute P(task correct | full queried mean route correct) from their intersection divided by actual route-correct support, never by a product of marginal rates. Record zero-support conditionals as null, and report complete suffix conditional on the same support. Retain paired fixes and breaks relative to unchanged; never summarize only a favorable net gain.

Compare the complete all-node used-route arrays of unchanged/shared-soft/shared-hard, not only aggregate scores. Original record/destination scores depend on public coordinates/instructions, not evolving hidden payloads; their mean-probability routes should coincide except possible floating-point averaging effects. Record exact equality and independently verify each queried mean-route conjunction agrees with the existing exact-path metric. Treat an unexpected mismatch as an audit finding, not an excuse to change the frozen model/policy.

Use the same queried oracle nodes and full path length for original record-head, original destination-head, used destination-head and mean-route accuracy. Report512event mean-route paths separately from4096event-head paths (eight heads); retain per-head counts, number of events where every head's full path is correct, and head-path correctness conditioned on actual mean-path-correct support. Also report per-query-step head correctness and unanimity. Full-path conjunctions, per-step means and all-node averages have distinct denominators and remain explicitly separated.

Keep original-address and used-address statistics separate under intervention. Oracle-common remains a privileged routing reference; its results cannot establish learned competence, a probabilistic ceiling or an acquired-soft gate. Unchanged A11 results remain historical endpoints. Local payload distortion uses current model payloads with properly summed numerators/denominators and cannot by itself establish gold representation fidelity.

Provenance chain: frozen A11 checkpoint/tensor hashes,53bdfed source-file inventory, unchanged config hashes, identical shared public arrays/events across all policies, no-update/final-tensor receipt, atomic full-process GPU receipt, and analysis input file hashes. Independent source preflight201aa8c passed; profile audit must precede main release. No new GPU run or policy is authorized by this plan.
