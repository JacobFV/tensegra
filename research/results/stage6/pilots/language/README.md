**Pilot metric limitation:** the old producer reports zero for undefined decoder precision/recall denominators. Raw node/edge populations were not emitted, so the analyzer cannot recover which zeros were undefined. Preserve this convention when reading pilot figures; the main producer adds counts and nulls. Per-run initialization and expected checkpoint digests were also absent. The archive records measured checkpoint SHA256 values but cannot independently verify paired initialization.
