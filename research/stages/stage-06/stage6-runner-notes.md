# Controlled Stage 6 runner

The runner separates public-only autonomous rollout from explicitly privileged teacher-forced training. It never supplies gold adjacency to the actor. Initial literal values are public. Returned numeric contents remain in the protected session and enter neural computation only through the learned typed-event injection. Public memory reveals capacity IDs, value availability and types. Context arrives exogenously with the final public evidence frame, independently of execution success. Positional hashed token features preserve ordered roles; this supplied feature prior is fixed across controls.

The actor predicts operation, ordered argument identities, write destination and local readiness. The global control replaces readiness logits by their candidate average and uses a shared sampled gate. Session type/availability checks remain independent of targets. The last compute pass never executes: every actual successful return is followed by at least one recurrent update, including event-drop. Output numeric class and binary context decision both read workspace output logits. Independent exact semantic and complete trajectory metrics audit the runtime separately from learned output.

Local/global/fixed-compute/runtime-off and annealing variants share parameter count, initialization seed and data schedule. `fixed` performs a single pass through the four distinct sublayers, with no runtime; `fixed_compute` reuses those same sublayers at every allowed microstep. They are a workspace transformer baseline and tied recurrent compute control, not pretrained language models. Main autonomous evaluation uses a common explicit budget of 80 microsteps across depths, sufficient to permit depth32 execution. Teacher training is limited to the shallow training budget. Learned halt time and forced-bound exits are recorded.

Grounding, full graph adjacency, selected proposal topology, operation/argument/destination transition, posterior readiness, task, emit, ponder, event roundtrip and policy losses are logged individually. Four auxiliary weights can anneal independently or together. Full-graph loss follows topology weight; roundtrip follows transition weight. Task-only cold and post-warm training sample actual predicted proposals/gates, consume actual session returns, use final task loss and REINFORCE with detached reward requiring correct exact numeric result and context output, and omit supervised emit loss. Discrete actions have no pathwise gradient. Emission receives task gradients through the differentiable hazard objective; discrete runtime actions use the separate policy gradient. All-zero auxiliary schedules also disable teacher forcing. Teacher-forced emit labels require the final context comparison to have executed, followed by a recurrent pass.

Event-drop, event-shuffle and wrong-value conditions alter the learned return channel while preserving exact session contents. Their standalone training names are intervention-trained controls; frozen-model evaluation interventions should be reported separately to support a causal claim. Public-graph is reserved and rejected because these episodes supply no public graph. Do not silently replace it with a hidden target graph.

Artifacts include step-zero and configured curves, checkpoints, model initialization hashes, complete public/privileged training-data hashes, per-example public hashes, source hashes including vendored compiler/renderers, raw proposed/executed/refused events, posterior calibration rows, projection overlap, grounding entropy/null mass, event roundtrip errors, numeric/context/task/exact-result/trajectory accuracy and undefined conditional denominators as null. Timing and fine-grained gradient/compute profiling remain to be expanded before broad quantitative claims.

Validation: seven remote CPU tests pass, including hidden-label mutation actor canary, future-observation isolation, ordered-context distinction, returned-scalar memory isolation, finite separate losses and configuration controls. No standalone training has been launched by this worker. Actual TCN surface-to-graph experiments belong to the separate language runner.

Before source freeze, independent review changed auxiliary annealing to hold full weight for the first quarter, decay linearly to zero by 75%, then train for a final zero-weight quarter. Frozen local checkpoints now receive drop/shuffle/wrong-value/runtime-off evaluation on the identical examples; these are the primary causal comparisons and include changed future actions. Evaluation conditions include held-out lexical rendering, genuine two-parent cross motif, and sub→mul composition withheld from training. Grounding loss uses candidate routes to pool structural query/key distributions and rewards probability mass on the candidate operand set, rather than supervising every workspace row toward every operand. Ordered argument binding remains a separate transition target. Full graph and selected topology labels preserve argument relation slots. Nine remote tests pass, including nonzero gradients for each auxiliary and event-induced changes to future action/output logits.

Roundtrip telemetry now explicitly separates `encoder` reconstruction from `post_recurrent_workspace` reconstruction. The latter decodes prior candidate-route pooling of the workspace after the next recurrent update; previous routes and event targets are held only by the loss/audit code and never passed to the actor. Both diagnostics are measured for frozen event interventions against actual executed values. The objective weights are task=1, graph=topology auxiliary weight, each named auxiliary its own weight, roundtrip=.1×transition auxiliary weight, emit=config.emit_weight only while auxiliary training is active, ponder=config.ponder_weight, policy=1. Thus all-zero/task-only phases retain no privileged auxiliary objective.

Step-zero/final local checkpoints also receive a clearly privileged oracle-trace diagnostic using exact teacher actions and full unroll, labeled separately from autonomous policy evaluation. It audits output/reintegration conditional on correct execution; it supplies placement and stopping privileges and must not be called learned reasoning. Ten remote CPU tests pass after typed graph/null-grounding model integration, including exact oracle trace and post-recurrent roundtrip presence.

## Adaptive compute objective correction before pilot

Training now unrolls the full allowed budget and optimizes task cross-entropy under differentiable halting hazard weights: eligible emission probability times survival to that step, with the final pass absorbing remaining mass. A returned event masks that step's emission; hard minimum and maximum still apply. The weights sum to one. Ponder is the expected microstep count under these same weights. Consequently task loss directly trains the emit probe even when all auxiliary weights are zero. Evaluation continues to use hard stopping. Existing supervised emit BCE applies only to runtime-enabled auxiliary conditions, never to baselines with no possible comparison register.

`neural_fixed` and `neural_recurrent` are separate zero-auxiliary, zero-runtime, zero-structural-bias controls with identical parameter layouts; the fixed variant has one cell pass. No oracle action/event forcing is used for either. They remain distinct from auxiliary-supervised `fixed` and `runtime_off` controls. Twelve remote tests pass, including hazard mass conservation/post-return masking and a nonzero gradient from neural task CE to the emit probe. `stage6-timing.json` is an eight-update, two-variant wiring/timing configuration; no training is launched by the worker.


Progressive local/global/runtime-off variants share the same exogenous evidence and context schedule. Pure `neural_fixed`/`neural_recurrent` instead form an explicitly labeled complete-evidence subgroup: both receive the final resolved public frame plus context from initialization. This makes their one-pass versus recurrent comparison an information-matched compute ablation. The legacy auxiliary `fixed` also receives complete evidence and is labeled accordingly; comparing it to progressively informed controls cannot establish a recurrence effect. Logs include `observation_protocol`, and stdout emits variant/checkpoint starts/completions with elapsed time. Thirteen remote CPU tests pass, including context arrival with an untouched runtime session and identical complete-evidence inputs for the neural pair.

## Final controlled freeze

`no_structure` retains runtime and all supervision while setting structural attention bias strength to zero. `protected_learned` preserves typed identities, availability checks and protected writes, but calls only `execute_learned` with values predicted by the shared roundtrip value head over candidate-routed workspace. Integer predictions are rounded/clamped to [-64,64]; boolean predictions threshold at .5. There is no exact arithmetic fallback. The transition-weighted `learned_transition` loss supervises these predictions. Repeated same-ID proposals use the first candidate value override; runtime proposal conflicts remain separately validated. Records explicitly identify the execution backend. Numerical agreement with gold for this arm is a learned-value correctness audit, not an exact-interpreter invocation.

Free emission is decided after the recurrent pass and before new execution. Training hazard eligibility uses that identical pre-execution state, then simulates the continuing branch for future weighted losses. A newly injected event must pass through a subsequent recurrent cell; duplicate events are neither reinjected nor counted as new pending returns. An unused supervised proposal slot receives a public dead/unbound candidate when available, including readiness zero, binding null and candidate-routed structural null targets. This remains auxiliary supervision, never an actor action mask.

Resolved manifests identify `evaluation_schedule=economy_v1`: step zero evaluates minimum/maximum depth anchors, intermediate checkpoints only minimum depth, final checkpoints the complete depth grid plus seven OOD cells (lexical surface, reordered words, cross motif, held-out composition, 16/64 distractors, four-frame ambiguity delay). Final local anchor checkpoints alone receive eight frozen interventions (drop/shuffle/wrong returns, runtime off, predicted-graph permutation/50% removal, readiness thresholds .5/.95), full-budget oracle traces, and `oracle_minimal` with the exact trace plus one post-return pass. Oracle placement/halting privileges remain explicit. Main readiness .8 and alternative thresholds are fixed probes, not tuned from results. Graph corruption modifies only used predicted adjacency, never targets.

Manifests contain source/config/git identities, initialization hashes, checkpoint state/file hashes and timing. Evaluation rows identify checkpoint hashes, observation protocol and execution backend. Eighteen remote focused tests pass after the final changes, including learned execution with the exact backend forbidden, duplicated proposals not preventing halt, ambiguity-delay alignment, and matching training/evaluation emission boundaries. Root owns full-suite verification and all training launches.
