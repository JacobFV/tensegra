# Claims and their prerequisites

These are independent research questions, not a single ladder on which every
failed surrogate blocks all subsequent work.

| Claim being tested | Necessary evidence | What does not establish it |
| --- | --- | --- |
| Opaque observation handles cannot affect content matching | Code-level separation plus consistent-renaming tests, preserving ledger equality | Correct final answers alone |
| Learned belief scores satisfy the restricted posterior contract | All registered framewise cells and seeds, including empty, contradictory and retracted evidence | The handle-invariance guarantee alone |
| A shared return interface works over a trained recurrent horizon | Workspace-only reconstruction of every required field, with zero-step and late-state results separated | Exact protected storage or a delay-specific diagnostic decoder |
| Return reconstruction extrapolates in recurrent length | Evaluation at lengths excluded from backbone and readout fitting | Accuracy at sixteen updates after training through sixteen |
| Public text supports complete fixed-set graph acquisition | Complete predicted graphs from public actor inputs on the fixed training set | Supplied node codes, gold inference masks, or component F1 |
| Text-to-graph generalizes | Fresh, identifiable constructions/surfaces evaluated under frozen decoding rules | Memorization of eight public texts |
| Programmable attention improves relational computation | A matched intervention comparing content attention with graph-induced attention bias, controlling observable information | Any Stage 11 result, which changes no structural attention |
| Learned interfaces can orchestrate exact computation | A separately authorized composition study with measured lowering, execution, return use and policy errors | Isolated interface passes |

Stage 11 inherits the restricted belief reference, tests return training support,
and begins public-text acquisition. Public-text acquisition does not depend on
passing return retention. Neither track is a universal prerequisite for another
direct structural-attention experiment. Autonomous composition and supervision
withdrawal remain blocked even if this stage's isolated gates pass.
