# Stage 4 binding losses and diagnostics

`binding_metrics.py` is a pure diagnostics/loss layer: gold paths are consumed here, never supplied to the model's forward pass. Ground loss balances pre-query, post-query, and real memory-key cross entropy equally. Null loss is binary cross entropy on the key null probability, balanced equally across real and distractor token groups (real group only when no distractors exist). Thus adding distractors does not silently increase the null objective's weight. Ground CE also penalizes null mass on gold real entities; null BCE is an additional explicitly weighted calibration loss.

Cycle loss is KL from the **detached predicted graph pushforward** to post-update grounding. The target appends retained null/unbound mass to the real-node pushforward. This is forward re-binding consistency, not inverse-edge reconstruction or a gold intermediate-state target. Detachment prevents target-side optimization shortcuts but does not exclude uniform/null fixed points. Low cycle loss alone establishes no correct grounding. Ground/null/cycle ablations must remain separately labeled.

Canonical state correctness is initial pre-grounding followed by each post-grounding, length D+1. Persistence/recovery counts compare consecutive canonical states, not overlapping pre/post pairs. First-error index is 0 for a wrong initial binding and D for a wrong final destination; D+1 denotes right censoring. Complete-path compatibility with Stage3 additionally requires *all* pre- and post-step groundings correct; canonical completion is separately reported. Their equality is expected for a shared unmodified grounder but is not silently assumed. Conditional rates divide pooled integer counts and return null when their denominator is zero. Empirical completion versus the product of canonical marginal accuracies is descriptive, not a causal attractor test.

Per-example arrays preserve joint features for failure associations; correctness trajectories serialize as compact bitstrings. Per-step floating-point diagnostics aggregate over examples, not stored as full probability tensors. Task correctness is injected by the evaluator as an independent per-example measurement. Distinct predicted-node counts include null if predicted, whereas distinct gold nodes cover the entire D+1 path.

`write_override_norm` measures the neural candidate minus the final identity write. It is mechanically zero for mixed-state writes and **does not imply zero content interference**. `mlp_identity_proposal_norm` measures proposed identity-coordinate change, which is applied in mixed updates and discarded by protected writes. Drift metrics compare current identity coordinates to immutable gold entity keys, in Euclidean and cosine distance. These are proxies rather than causal Jacobian measurements.

Relation attention mass is summed over supplied-graph successor support from the gold source. In graph-input mode the attention addresses source memory slots whose values are transformed into successor messages; consequently next-token attention mass is not the same mechanism diagnostic as in direct structural routing. Grounding and task measures remain comparable; do not infer graph-input failure from destination-token attention mass.
