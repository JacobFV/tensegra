# Stage7 A/B acquisition scope

A consumes supplied typed instruction records (destination key, operation cue, ordered operand keys), shuffled with distractor instructions, and a public destination query. Two learned attention stages retrieve the matching record and bind ordered register pointers. Output labels never enter model forward. The task measures typed instruction selection and binding, not language understanding, graph traversal, arithmetic execution or runtime composition. IID has leaf/chain dependencies; moderate OOD adds larger register/instruction sets and two-derived-operand wiring. Names/value ranges are randomized metadata-only invariance axes and cannot support value/name comprehension claims. Compare outputs are boolean sinks; arithmetic operands use numeric registers.

B consumes generator-supplied confidence factors, exact schema validity and a stability feature that is independent of future evidence. Shared latent evidence makes the factors correlated. Correctness is sampled after factors, with overlapping support and stable high-support wrong cases. The synthetic calibration law has a sharp probability transition at latent .9985: this tests score calibration, not evidence inference or candidate construction. The product is only a score. Calibration parameters train on calibration data; thresholds freeze on validation. Local/global/product thresholds use the same precision requirement. Mixed readiness groups are separately scored. Schema validity is architectural and separately logged.

Tiny delta diagnostic predicts an inserted value from supplied operation and operands. Removal identities and output type are supplied, not predicted. Compare preserves the existing boolean less-than semantics. There is no new rewrite runtime.

`python -m topoformer.interface_study --config configs/stage7-ab-smoke.json --output DIR` writes source/config/data/model hashes, raw predictions, per-component losses, step-zero curves and gate support counts. Test outcomes are evaluated only with `main_budget_frozen=true`; acquisition defaults to validation only. A gate requires every configured seed and both IID/OOD validation cells, strict component >99%, full >98%, noncommutative order >99%. Empty/missing cells fail. Progressive and runtime composition remain blocked. Smoke/acquisition configs are provisional, not frozen main budgets.
