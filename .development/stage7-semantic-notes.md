# Stage7 semantic acquisition

`python -m topoformer.semantic_scaling --config configs/stage7-semantic-acquisition.json` runs the independent acquisition probe. Run on gb10-direct with OMP/MKL threads<=2 and the pilot venv, in a fresh directory. No symbolic runtime coupling exists. The larger 1k/10k/100k configs are proposals, not authorization or completed runs; 1M is deferred until measured feasibility and finite-family support are known.

The pinned existing TCN adapter/compiler is unchanged. SQLite stores seed/lesson plus complete alpha-normalized graph strings with a UNIQUE constraint. It materializes individual examples on demand. Renaming or rendering an example cannot inflate its semantic construction count. Normalization preserves repeated entity equality, all nonidentity values, node types, edges, and explicit argument slots. Requested cardinality, attempted candidates, actual unique graphs and duplicates are recorded separately. Reaching the attempt cap is explicitly **not** a proof that the finite family is exhausted. Insufficient cardinality aborts before training and preserves the corpus audit.

All renderings of a construction share its split. Training exposes English/Spanish, while symbols is a whole heldout renderer. Heldout lexicon uses consistent new variable and entity identifiers. The decoder sees only public text, builds lexical tokens without a semantic parser and learns pointers to visible identifiers. Gold pointer targets use the pinned renderer to handle translated identifiers, and canonicalize repeated occurrences by token spelling. There is no hash-only success criterion. Nonidentity values use a train-only vocabulary; unseen values always fail exact semantics.

The existing ThinkingModel cell feeds fixed decoder query positions. Presence, node types, categorical values, copied identities, typed edges, and ordered argument slots are supervised separately. Exact graph recovery is measured under the pinned compiler traversal alignment, including identity and ordered-slot correctness. This is a restricted canonical structural comparison, not general graph isomorphism, semantic execution, or denotational equivalence. Slot order and fixed type/role ontology are supplied priors. Pairwise entity-equivalence accuracy can be inflated by unequal pairs; exact copy and full graph metrics are also reported.

A train-only elementwise frequency decoder and a parameter-matched no-input neural decoder provide baselines. The no-input arm has constant context and receives the public token candidate count for its pointer output, but no token identities. Same-family different-graph controls record token overlap and exact structural disagreement; these are dataset negative controls, not a learned sensitivity result. Raw per-example predictions/targets/text are gzip JSONL for independent reconstruction. Curves include step0, optimizer examples, distinct graphs actually visited, token exposure, fixed-training-set acquisition, all three renderers and heldout lexicon. The initially proposed 10k optimizer updates at batch2 expose at most20k distinct graphs; comparing that to nominal100k cannot establish a full100k-data scaling result.

GateF stays false until a cross-budget paired-seed analysis demonstrates positive heldout typed-edge and full-semantic trends above baselines and meaningful heldout-renderer/lexicon transfer. Presence alone cannot pass. No downstream coupling follows this probe. Config/data/source/compiler/renderer/initial/final/checkpoint hashes are recorded for reuse.
