# Stage 6 methods: recurrent workspace and protected execution

This stage has two separate experiments: controlled arithmetic execution and TCN surface-to-semantic decoding. They share the four-phase recurrent cell and canonical graph schema; they do **not** form an integrated language-controlled runtime. The design is in [stage6-design.md](stage6-design.md), and results/coverage are in [stage6-report.md](stage6-report.md). Frozen run manifests, rather than the current checkout, identify the implementation measured by each experiment.

## Model and supplied interfaces

[ThinkingModel](../src/topoformer/thinking.py) maintains eight distributed workspace rows of width 32 by default. One microstep applies four distinct attention/MLP blocks; the same four blocks are reused at subsequent microsteps. Each block has workspace self-attention, public-context/current-memory cross-attention, and an MLP. Only the current workspace is recurrent state: there is no latent-history Q/K/V cache. Candidate queries softly pool overlapping workspace components. Candidate output slots predict primitive, ordered argument pointers, public destination identity and local readiness; neither candidate slots nor workspace rows define a thought ontology.

Two of four heads receive an induced structural bias, with independently normalized query/key grounding distributions and explicit null destinations. A context-refreshed memory representation predicts typed adjacency. For relation r the bias is proportional to Pq A[r] Pk-transpose, with learned head/relation strengths. Null grounding is excluded from graph edges; the other heads receive no structural bias. Zero structural strength removes this bias. Hidden target adjacency is never substituted for the actor's prediction. A supplied observable graph is supported by the cell API, but the controlled runner rejects its reserved `public_graph` arm because this dataset has no such graph.

The [controlled generator](../src/topoformer/thinking_tasks.py) supplies typed literal memory, named result capacity, clause segmentation, operation IDs, bounded values, and three externally arriving full-program evidence frames. These are substantial priors. Primitive/ordered-operand alternatives narrow across frames, with local uniform-hypothesis readiness labels of 1/4, 1/2 and 1, or zero when operands are unavailable. These labels describe local ambiguity, not a posterior over all dataset restrictions. Readiness supervision is separate from formal type validity and never masks free-policy proposals.

Two arithmetic lanes produce a numeric lane-0 target and a downstream ordered comparison. The comparison needs both returned values and a separate public ordering cue. In the runner, the cue arrives exogenously with the final evidence frame regardless of execution success. Complete-evidence neural controls receive that frame and cue from initialization. Fixed position-sensitive hashed public features preserve operand order. Actor memory exposes literal values, IDs, availability and types; **returned scalar contents are withheld from this memory feature channel**. Same-result/opposite-context diagnostics condition on unequal roots. Heldout conditions include lexical rendering, a genuine two-parent cross dependency, and a sub→mul composition excluded from training. These are controlled structural/composition tests, not unrestricted language induction.

## Protected transitions and learned reintegration

The [protected session](../src/topoformer/thinking_runtime.py) accepts immutable typed literals and predicted candidates. Its fixed primitive subset is add, sub, mul, neg and ordered less-than comparison. Integer operations are exact within configured bounds; float operations use finite Python floating-point semantics. The formal schema records operation, signatures, validity constraints, transition semantics and external lowering/lifting hooks. A valid operation can still be wrong for the task: validity checks never consult gold correctness.

All proposals in one call read the same prior-state snapshot. Independent operations and shared read-only operands may execute together; same-batch results become available on the next call. Incompatible proposals with the same destination identity conflict symmetrically. Identical retries are idempotent; invalid proposals cannot mutate protected state. Successful transitions append typed registers and events with operation, ordered arguments, value/type, destination and provenance. This is an append-only scalar transition library, not a general graph-rewrite engine; it has no arbitrary scope mutation, undo or recursive rewrite system. The Python interface is not a security sandbox against hostile reflection.

A learned encoder maps each typed event into a vector and adds it through the candidate's soft route. No residual workspace component is deleted. The driver requires another recurrent update after every successful return, including a dropped return message, before emission; its last pass executes no operation. Numeric and comparison output classifiers read pooled workspace only. Persistent exact registers therefore remain distinct from learned output reconstruction. Encoder reconstruction and reconstruction from the post-recurrent workspace are logged separately. The latter uses stored routes only in loss/audit code, not as actor input.

Frozen-checkpoint drop, route-shuffle and wrong-value interventions alter the neural return channel while preserving exact session contents. Subsequent actions can change, so these estimate total policy consequences of the intervention, not an effect conditional on fixed future execution. Separately trained intervention arms are distinct controls. A privileged oracle-trace diagnostic forces exact action placement and full unroll and is reported separately from autonomous evaluation.

## Learning, halting and auxiliary withdrawal

[thinking_study.py](../src/topoformer/thinking_study.py) separates teacher-forced training from free-policy evaluation. With auxiliary support, trace-aligned gold actions are executed during training, and hidden graphs/readiness/transition labels supervise predictions after public forward computation. Free evaluation supplies only the public episode and uses predicted primitive, ordered operands, destination and readiness, followed by actual protected transitions. Hidden-field and future-observation canaries test frozen actor invariance. Gold values used for subsequent scoring are not inference inputs.

Four auxiliary weights—grounding, topology, transition and readiness—can decay independently or together. Grounding rewards candidate-route-pooled operand-set mass without labeling every workspace row; ordered binding has its own transition loss. Full-graph loss follows topology weight and event roundtrip loss follows transition weight. The implemented schedule holds full weight for the first quarter, decays to zero by three quarters, then retains a zero-support final quarter. Cold task-only and supervised-warm-start task-only are separate arms. When all auxiliary weights are zero, teacher-forced proposals and supervised emit BCE are disabled.

Training unrolls the complete budget. Let p[t] be the eligible emission hazard and s[t] survival to step t. Nonfinal mass is w[t] = s[t] p[t]; the final pass absorbs remaining survival, so the weights sum to one. Same-step successful returns mask emission. The task objective is sum_t w[t] CE[t], and ponder cost uses sum_t t w[t]. Thus task correctness differentiably trains the emit probe even with no auxiliary losses. This is an ACT-style hazard objective; evaluation uses hard stopping, not a weighted mixture of answers.

Discrete runtime proposals have no pathwise gradient. Task-only training samples primitives, argument/destination pointers and readiness gates and uses REINFORCE with an exponential moving reward baseline. Reward requires correct exact lane-0 result and final learned context decision. It is a terminal full-unroll policy surrogate distinct from the survival-weighted classification objective. It does not by itself demonstrate acquisition of useful actions or learned stopping.

The reviewed pre-main objective is task + weighted four auxiliaries + topology-weighted full-graph loss + 0.1×transition-weighted roundtrip + auxiliary-only emit BCE + ponder + policy loss. Loss components and weights are logged separately. The current controlled implementation's soft stop prior is independent of the hard budget: sigmoid(probe − alpha softplus(soft_min−t) + beta softplus(t−soft_max)). Hard minimum/maximum still clamp emission. This correction postdates the frozen language source and must be identified by the controlled manifest. Token time is an explicit cell input, but these experiments emit one answer/choice, not a multi-token autoregressive sequence.

## Controls and budgets

The pure `neural_fixed` and `neural_recurrent` pair shares complete public evidence, parameter layout and zero runtime/structure/auxiliary support. It isolates one versus repeated cell passes under matched information, not matched compute. Progressive `local`, `global` and `runtime_off` conditions share the exogenous observation schedule. The global control averages readiness logits and, during sampled training, shares a gate. Comparisons across complete/progressive protocols cannot isolate recurrence. `fixed_compute` forces the full recurrent budget. Task-only cold/warm and each independent auxiliary withdrawal address distinct acquisition/maintenance questions.

`no_structure` and `protected_learned` controls are under implementation at initial drafting; they are not measured arms until a frozen configuration and implementation define them. In particular, a learned-return comparison must disclose which validity, memory and value guarantees it retains. No result is attributed to either pending arm here.

The controlled main configuration/source/budget remain pending in the report. [stage6-timing.json](../configs/stage6-timing.json) is an eight-update, one-seed, two-arm resource/wiring run and is not a main study. The runner supports shallow training with depth 8/16/32 evaluation and an 80-microstep evaluation cap. Actual executed depths, caps, checkpoints and wall-time completion must be read from the final artifact grid.

## Independent TCN language experiment

The [adapter/compiler](../src/topoformer/tcn_data.py) vendors the MIT-licensed TCN language engine at commit `018c9ce9286fa4961292fe1e024b49fcd7e2dd7f`, retaining [file hashes and license](../src/topoformer/_vendor/tcn_language/MANIFEST.json). Variable-binding, unification and set-operation lessons generate one immutable semantic construction, then render it into English, Spanish and symbols. Same-seed regeneration across languages is not used as evidence of matched meaning. The canonical graph has typed nodes, ordered argument/list edges, construction scope, bindings and provenance. It is a structural compiler, not inferred arbitrary lexical scope or executable TCN rewrite semantics.

[LanguageActor](../src/topoformer/thinking_language.py) accepts only text and shuffled visible choices. Teacher graph, answer index, node count, generator metadata, renderer label and audit IDs are excluded from forward inputs. Public Unicode token chunks use deterministic 64-bit hash/position features. A fixed 128-position decoder reads current workspace and predicts node presence/kind, lexical hashes and typed edges. Decoder positions follow canonical traversal and are not semantic labels on workspace rows. Exact graph metrics require canonical alignment, not graph-isomorphism matching; argument slots are implicit in positions, and whole-hash fidelity is not string generation.

[The frozen main configuration](../configs/stage6-language.json) uses 240 training constructions, 48 heldout constructions, seeds 7/19/43, 256 updates, batch 4, learning rate 0.001, and evaluations at 0/64/128/256. Four arms are single-pass, three-step recurrent, graph-supervised recurrent, and graph-supervised recurrent with paired English/Spanish consistency. Parameters initialize identically within each seed. The last arm adds Spanish task exposure as well as consistency, so its difference cannot isolate a consistency-loss effect. Spanish is unseen only by the first three arms; symbols is unseen by all arms. Additional English evaluation consistently alpha-renames answer entities to a small reused novelentity vocabulary.

Semantic digests deduplicate constructions and separate train/evaluation identities. They do not guarantee disjoint alpha-equivalence classes, entities, motifs or compositions. The language track evaluates choice accuracy and semantic decoding with fixed compute; it does not execute predicted graphs, train runtime actions or test adaptive emission. Source `4c36557` is the language-main freeze; later controlled changes must not be retroactively attributed to it.

## Artifact analysis and interpretation

[The analyzer](../src/topoformer/thinking_analysis.py) reads completed artifacts without training or loading model checkpoints. Reports retain per-seed means/sample SD, paired contrasts, support counts, undefined rates as null, provenance and missing-grid audits. Seed variability is not a confidence interval over arbitrary tasks. Macro decoder precision/recall and pooled count-based rates are distinct. The evaluation-majority-position language baseline is explicitly privileged; random choice is separately reported.

Source, config, data, initialization and saved-checkpoint hashes establish reproducibility within the recorded protocol. The analyzer rejects inconsistent identities/duplicate rows and reports source mismatches. A current-source mismatch against an older frozen run is expected only if explicitly accounted for. Main findings require the full declared grid and completed manifests; partial outputs and eight-update pilots are not substituted for that evidence. Architectural correctness, supervised diagnostics, autonomous learned behavior, exact symbolic results and learned output fidelity remain separate claims.
