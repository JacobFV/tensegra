# Track C implementation and scope

The full Stage7 design supersedes the initial stage7a joint retention/use curriculum. C1 optimizes six workspace reconstruction losses only (value, type, operation, ordered argument0, ordered argument1, provenance). Task and validity heads are untrained diagnostics in C1. `phase != C1` is rejected: C2 needs a root audit of all validation seeds before a separate supervised return-use phase. No proposal, execution, halting or composition code exists here.

Three nominal paired training arms share all parameters, initializations, batches and delays: once additive injection; immutable protected register available through the existing blocks' crossattention; protected register with a learned read gate. `persistent` is the gated checkpoint evaluated with an independently owned durable record surviving delayed register loss. It is mathematically identical during ordinary availability and is not separately trained or counted as an architecture advantage. Release and overwrite are lifecycle interventions, not extra training arms. They never reset free workspace. Release invalidates both stores, overwrite replaces both; current storage presence is a public recurrent input. Learned validity and stale old-fact decode are distinct from exact architectural register integrity. C1 does not establish learned lifecycle validity.

The event is copied on ingress and read. The generic cell cannot write it. Event encoding and four existing ThinkingModel blocks are reused; unused ThinkingModel machinery is retained equally for matched parameter counts but never called. All heads decode only pooled free workspace. Identity heads compare projected workspace with shuffled independent nonce key tables; unary neg uses an explicit null second operand. Values are finite half-unit classes; floating type includes integer-valued values. Public operand scalars witness semantic event correctness; the event encoder consumes the existing supported fields. These supplied structured events and nonce identities are strong input priors.

The query enters only after exactly the configured retention updates and requires one additional four-block pass. Pre-query reconstruction has no query dependency. Unrelated distractors vary by recurrent update. Sign-flipped distractors probe sensitivity to unrelated activity, not preservation of a separately learned unrelated fact. No such stronger preservation claim is made.

Runner records step0 and per-field losses/counts, batch/source/config/initial/checkpoint hashes, checkpoint tensors, per-example predicted classes and separate targets, exact denominators, drift, and validation/test split labels. `test_seeds` is optional and must be disjoint from validation; final main configuration should provide untouched test seeds. Strict 16-update gates require every configured validation seed × distractor condition. Empty or missing support fails. Return-use gate is reported as an untrained C1 diagnostic, never an authorization. Fixed acquisition runs always mark dependent experiments blocked. C1 acquisition uses joint retention >=99% on the fixed set; heldout main gates remain separate. Main budgets/seeds/support must be frozen by root before training.

Configs provided: stage7-c-overfit.json (fixed32-example acquisition) and stage7-c-timing.json (two optimizer-step timing proposal). Neither has been run. Only remote pytest, including zero-optimizer-step runner artifact verification, has run under two CPU threads in isolated `/tmp/stage7-c-tests.zHDsxU`; no local Torch execution. The initial expected missing-module tests failed before implementation. Nine scoped tests now pass. Full-suite status is reported separately to root because concurrent tracks and remote snapshot metadata can affect it.
