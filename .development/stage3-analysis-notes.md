# Stage 3 artifact analysis

`python -m topoformer.grounding_analysis METRICS.jsonl OUTDIR --seeds 0 1 2` reads committed metrics only. It requires a complete variant × condition × expected-seed grid, one shared configuration/source identity, finite metrics and matching training-schedule/evaluation-data hashes before paired comparisons. Common initial parameter hashes are checked separately because initialization ablations intentionally differ. Missing distractor-null accuracy when no distractors exist is N/A, not zero. Seed summaries use sample SD; no inferential significance or confidence claim.

The report separates task accuracy, complete pre/post grounding paths including destination, complete attention argmax paths, and pre-step-only grounding. Probability and entropy diagnostics remain separate. Deterministic direct/one-hot attention oracles are privileged algorithms. Known and graph-input controls use fixed cosine soft identity matching. Primary learned soft begins with an identity-coordinate prior; random initialization remains a separately labeled variant. Names are random continuous identities, not lexical language.

Optional Matplotlib figures are standalone PNG/SVG depth, size, corruption and distractor curves plus recurrent-step diagnostics. Every figure fixes other experimental factors rather than implying a joint depth × size sweep. First-example trajectory tables are selected by seed/condition, never by success. Resource tables distinguish instrumentation-inclusive run time and plain inference time; process peak RSS is a high-water mark, not model memory allocation. Raw model records preserve strengths and temperatures.

Validation: nine focused tests passed remotely on GB10, covering sample SD, incomplete/duplicate seed grids, nonfinite metrics, mismatched evaluation pairing, unavailable distractor metrics, mixed provenance, and explicit metric semantics. No training is performed by the analyzer. Source schema locked against runner commit `2220217`; actual artifacts will be checked once the run is complete.
