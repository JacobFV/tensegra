# Stage 3 recurrent traversal model

`TraversalTransformer` preserves the original predictors untouched. It updates one query residual over an immutable, randomly shuffled memory of identity keys and categorical payloads. Each externally supplied relation instruction invokes one shared block; the projection-period ablation cycles a trained set of projections. Deeper evaluation receives more compute, not unseen new layer weights. This is relation-instructed recurrence, not inferred execution scheduling.

The residual uses a learned interpolation gate toward the retrieved identity/payload memory followed by an MLP. This permits identity replacement rather than accumulating every visited entity. Ordinary content attention operates throughout; all modes have identical update/readout parameters. Zero structural strength yields numerically identical ordinary attention. No diagnostic labels, intermediate nodes, or answer enter `forward`.

The default grounding projection uses an explicit identity-coordinate prior: latent prefix selects the random unit identity key, with scale cancelling the grounding kernel's square-root dimension factor. Entity projections start as identity. Query/key projections subsequently learn separately. Fixed cosine matching provides the `known` control; the `identity_init=False` ablation starts random projections. This experiment does not claim discovering semantic identity from arbitrary language. Temperature defaults to .05 and initial structural strength to 8; these intentionally enable a routing feasibility test and must be reported as a potentially near-hard prior. Null starts with similarity threshold .65.

`soft` recomputes grounding per step; `frozen` reuses its initial distributions; `permuted` cyclically misaligns query assignments; `hard` argmaxes query/key grounding and restricts attention to directed legal targets, falling back to ordinary attention when no target maps. `none` retains ordinary attention. `graph_input` uses fixed cosine-grounded graph messages as the value features of ordinary attention, with no graph logit bias. This is a message-passing control, not raw serialized edge tokens, and its identity mapping is soft, not a hidden token-node label lookup. All modes receive the relation instruction through a content-query embedding.

Diagnostics retain per-step query/key distributions, attention weights, induced relation bias, head strengths, and updated state. The returned `pq` is the pre-update grounding for the current instruction. Accuracy of that distribution should therefore compare to `path_nodes[:, step]`; attention should compare to `path_nodes[:, step + 1]`.

Validation: gradient flow to query/key projections, strength, and learned temperature; exact zero-strength equivalence; public-input-only forward; recompute/freeze distinction; all mode finiteness; token permutation and graph slot permutation equivariance; cyclic projection reuse at deeper unrolls. Tests run on SSH CPU with two BLAS/OpenMP threads.

Hard argmax routing does not backpropagate task loss into grounding projections; it is an initialized fixed-routing control with trainable content/value/update/readout weights. Known cosine matching normalizes the query identity prefix while learned grounding uses learned dot products, so their norm sensitivity also differs. Plain `none` inference skips unused grounding and induced-bias computation; diagnostic inference computes probes intentionally. Compute comparisons must time `return_diagnostics=False` separately from diagnostic collection.

`pq_after` additionally probes the updated state against the same current grounding module, including the final step, for exact path completion. In frozen mode this is observational only: attention still uses the frozen initial distributions. Permuted mode applies its same wrong coordinate permutation to the post-state probe. These diagnostic probes are excluded from ordinary inference timing.

## Supplemental content retrieval prior

The bounded keyed supplement adds an optional, graph-independent content logit `beta * cosine(current_state_key_prefix, raw_token_key)` equally to every attention head. It uses no new learned parameters, no graph adjacency, and no ground-truth token-node labels. Default `content_identity_bias=0` skips the calculation entirely. The supplement sets beta=8 and structural initialization=16 for all three matched `soft_keyed`, `graph_input_keyed`, and `none_keyed` variants (strength is unused by the latter two). These are preset feasibility controls, not settings selected on deep test performance.

This addresses an initialization confound: soft graph routing had an identity-grounding prior, whereas graph-message values still required learning current-entity content retrieval from randomly initialized Q/K. The supplemental content prior supplies that matching preference to every compared mode. It changes the architectural prior and should be reported separately from the main experiment. In graph_input, the graph still affects values only; subsequent state-dependent content scores may differ after graph messages change the state. Graph independence of the content kernel is conditional on the same input state, not an assertion that whole trajectories ignore the graph.

Validation: ten model tests passed, including exact zero-default behavior, graph-independent content logits for equal states, zero-structure equivalence with the prior, public-input-only execution, and finite nonzero content-projection gradients. A separately loaded pre-change module also produced identical RNG state, state-dict tensors, and bit-exact outputs for all seven original modes under the default setting.
